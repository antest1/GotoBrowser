## 設定 

ツールバーが表示されている状態で、ゲーム画面の右上にある歯車アイコン(<span class="material-symbols-outlined inline-icon">settings</span>)をタップしてアクセスできます。

- 設定画面はゲーム画面の上に表示され、ゲームは後ろで動作し続けます。
- 上部のハンドルを下にドラッグするか、戻るボタンを押すと閉じます。
- 右上のヘルプボタン(<span class="material-symbols-outlined inline-icon">help</span>)を押すと、このマニュアルが開きます。

<img src="https://gotobrowser-docs.s3.ap-northeast-1.amazonaws.com/ja/settings_main.webp"  width="560" style="max-width: 100%;" class="mb-3"/>

##### 設定の反映方式

| 反映 | 説明 |
| --- | --- |
| 即時 | 値を変更するとすぐに反映されます。 |
| 再読み込み | 「再読み込みが必要です」ダイアログが表示されます。「今すぐ再読み込み」を押すとフルリフレッシュ後に反映され、「再読み込みせずに設定を変更」を押すと次の再読み込み時に反映されます。 |

<img src="https://gotobrowser-docs.s3.ap-northeast-1.amazonaws.com/ja/settings_refresh_required.webp"  width="480" style="max-width: 100%;" class="mb-3"/>

##### ログインと接続

| グループ | 名前 | 説明 | 反映 |
| --- | --- | --- | --- |
| ゲームログイン | ログインオートコンプリート | ログインフォームに自動入力するIDとパスワード。デバイス内にのみ保存されます | 再読み込み |
| ゲームログイン | ログアウト | ゲームからログアウトし、コネクタのログインページに戻ります | |
| ブラウザ設定 | 接続方式選択 | DMM direct（デフォルト）/ ooi.moe<br/>非公式のコネクタを初めて選択すると、ゲームリソースに関する案内が表示されます | 再読み込み |
| ブラウザ設定 | 音量OFFでスタート | ゲーム起動時にゲーム内のBGM/SE/VOICE音量を0に設定します（公式アプリ機能と同じ）<br/>DMM directでのみ使用できます | 再読み込み |
| ブラウザ設定 | ブロードキャストモード | 艦これ関連の通信内容をKcanotifyなど他のアプリケーションで使用可能にします（デフォルトで有効）<br/>Kcanotifyと連動するためには必ずオンにしておく必要があります | 即時 |
| 国外ブロックのバイパス | 国外ブロックのバイパス | 海外IPブロックの問題（無限の黒い画面）が発生する場合に有効にします | 再読み込み |
| 国外ブロックのバイパス | バイパス方式 | URL置換またはKCCacheProxy（リモート）を選択（ほとんどの場合「URL置換」を使用） | 再読み込み |
| 国外ブロックのバイパス | エンドポイントサーバー | バイパスに使用するサーバーのURL<br/>`https://kcwiki.github.io/cache/`（デフォルト） | 再読み込み |
| 国外ブロックのバイパス | バイパスの自動無効化 | ブロックされずに接続できた場合、バイパスを自動的に無効にします（デフォルトで有効） | 即時 |

バイパスについては<span class="link" data-move="gadgetbypass">海外IPブロックバイパス</span>ページを参照。国外ブロックのバイパスが無効の間は、バイパス方式とエンドポイントサーバーは選択できません。

##### ゲーム画面表示

| 名前 | 説明 | 反映 |
| --- | --- | --- |
| 横画面に固定 | デバイスの向きに関係なく常に横向きでプレイします（デフォルトで有効） | 即時 |
| レイアウト自動調整 | ゲーム画面をデバイスの画面サイズに合わせて自動で拡大/縮小します（おすすめ、デフォルトで有効） | 再読み込み |
| ゲーム画面の縦位置 | 縦画面や分割画面などでゲームの上下に余白がある場合、ゲームを中央または上に配置します（デフォルトは中央） | 即時 |
| PIPモードを有効にする | ホーム画面に戻るか、ゲーム画面をピンチイン（縮小）すると、小さなフローティング窓でゲーム画面を表示します | 即時 |
| [マルチウィンドウ] 分割バーから余白を追加 | マルチウィンドウ機能を使用するときに画面が分割バーに直接貼らないように余白を追加します | 即時 |
| レガシーレンダラを使用する | WebGLレンダリングの代わりにCanvasレンダリングを使用します（グラフィックの問題が発生しない場合は無効を推奨）<br/>有効にするとKantai3Dは使用できません | 再読み込み |

PIP/マルチウィンドウについては<span class="link" data-move="pipmode">PIP/マルチウィンドウ</span>ページを参照

##### 操作とツールバー

| グループ | 名前 | 説明 | 反映 |
| --- | --- | --- | --- |
| ツールバー | 起動時にパネルを表示 | アプリ起動時にツールバーが表示された状態で開始します（デフォルトで有効） | 次回起動 |
| ツールバー | 確認なしでリフレッシュ | リフレッシュボタンを押したときに確認なしですぐに画面を更新します | 即時 |
| ツールバー | ツールバーの表示位置 | 中央（デフォルト）または上・クラシック。上・クラシックにすると3.xと同じく、ツールバーを画面の上に寄せ、リフレッシュボタンを一番上に置きます。横画面で適用 | 即時 |
| ツールバー | 端からスワイプしてツールバーを表示 | ツールバーが隠れている画面の端から内側にスワイプしてツールバーを表示します（デフォルトで有効）<br/>オフにすると、端のスワイプはシステムのジェスチャーだけに使われます<br/>余白がない画面では、戻るボタンでツールバーを表示します | 即時 |
| ゲーム操作 | キーボード入力を有効に | ゲーム画面でキーボード入力を使用するかどうか（デフォルトで有効） | 即時 |
| ゲーム操作 | 入力モード | ゲームプレイ時の入力方式を選択（画面タッチまたはマウス使用） | 再読み込み |

##### キャッシュ設定

| 名前 | 説明 | 反映 |
| --- | --- | --- |
| キャッシングに外部ストレージを使用 | ゲームリソースをキャッシュするときに内部ストレージの代わりに外部ストレージを使用します（おすすめ）<br/>（PCから画像/ボイスのリソースにアクセスしたり編集したりできます） | 再読み込み |
| フォントをプリロード | ゲームサーバーからフォントを読み込む代わりに、アプリに内蔵されたフォントファイルを使用します（おすすめ、デフォルトで有効） | 再読み込み |
| ゲームアセットのダウンロードの再試行 | サウンドや画像アセットのダウンロードに失敗した場合、再試行するかを確認するダイアログを表示します<br/>不安定なネットワーク環境による猫を減らせます。ゲームデータAPIには適用されません | 即時 |
| キャッシュ削除 | ブラウザ内のキャッシュを削除します。画像や音声が正しく読み込まれない場合や、ログイン方法を切り替える場合に使用します<br/>削除後は再度ログインが必要になることがあります<br/>削除が終わると再読み込みの案内が表示されます | 即時 |

##### 字幕設定

| 名前 | 説明 | 反映 |
| --- | --- | --- |
| 字幕ロケール | English / 한국어 / 日本語 (KC3改)、简中 / 繁中 (kcwiki) から選択 | 即時 |
| フォントサイズ | 画面内のボイス字幕のサイズを調整します（12～24、デフォルト18） | 即時 |
| 字幕データのダウンロード | データの更新がある場合にダウンロードできます。ダウンロード直後に反映されます | 即時 |
