## PIP/多視窗

<img src="https://gotobrowser-docs.s3.ap-northeast-1.amazonaws.com/zh-tw/pip_multiwindow.webp"  width="550" style="max-width: 100%;" class="mb-3"/>

GotoBrowser 支援 PIP 模式與多視窗功能。（Android 8.0 以上，Samsung Galaxy 為 7.0 以上）  
利用此功能，可以在裝置上進行其他工作的同時遊玩艦C。

##### PIP 模式
- PIP 模式下只能查看目前的遊戲畫面，若要實際遊玩，必須結束 PIP 模式。
  - 在 PIP 畫面上按 X 時，不會結束應用程式，而是切換至背景狀態。
- 在設定 → 遊戲畫面顯示中開啟「啟用畫中畫模式」後，可透過以下方式進入 PIP 模式。
  - 按主畫面按鈕或往上滑動，返回主畫面
  - 在遊戲畫面上以兩指往內捏合（雙指縮小）
- 「啟用畫中畫模式」關閉時，返回主畫面後會切換至背景狀態。
- 進入 PIP 模式時，已開啟的設定畫面會關閉，重新整理／登出的確認視窗會被取消。

##### 多視窗模式
- 在多視窗（分割／彈出視窗）狀態下可以正常遊玩。
- 顯示及隱藏工具列可使用<span class="link" data-move="browserui">與一般相同的方法</span>。（輕觸空白處或滑動）
- 若遊戲畫面緊貼分隔條，請在設定 → 遊戲畫面顯示中開啟「[多視窗模式] 在分隔條增添間隔」。
