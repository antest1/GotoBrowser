## 隐私政策

**Updated: 2026.11.07** (初版)

GotoBrowser（以下简称“本应用”）是一款可在 Android 设备上游玩舰队Collection（HTML5）的开源浏览器。开发者未运营任何用于收集用户信息的服务器。本政策说明本应用所处理的信息及其处理方式。

##### 保存在设备上的信息

以下信息仅保存在您的设备上，不会发送给开发者。

- 应用设置
- 自动登录信息（ID/密码）：仅在您于设置中输入时保存，且仅用于在登录页面自动填写。密码使用 Android 密钥库中的密钥加密保存。该密钥不会离开您的设备，因此若在其他设备上从备份恢复应用数据，将无法读取密码，已保存的密码会被删除。
- Cookie、登录会话及游戏资源缓存
- 截图：您截图时保存到设备的图片文件夹中。
- 用于 Kcanotify 联动的游戏通信数据：保存最近的部分通信记录，其中不包含认证令牌。

##### 与游戏及连接服务的通信

本应用为游玩游戏而与 DMM 及舰C服务器通信。若您选择由第三方运营的网页代理服务作为连接方式，包括登录信息在内的游戏通信将经由该服务传输。此类服务与开发者无关，适用其各自的隐私政策。若启用海外IP封锁绕行功能，部分游戏资源请求将发送至所设置的替代服务器。

##### 对游戏的影响

本应用不会修改与舰C及 DMM 服务器之间的通信内容，也不提供任何影响游戏的宏或作弊功能。

##### 与 Kcanotify 联动

启用广播讯息方式时（默认），本应用会将游戏通信内容传递给同一设备上安装的 Kcanotify 应用，其中认证令牌会被替换为任意值。这些数据不会离开您的设备，您可以在设置中关闭广播讯息方式。

##### 错误报告及使用统计

为发现并解决问题，本应用使用 Google Firebase（Crashlytics、Analytics）。可能会收集错误信息、设备型号、操作系统及应用版本等设备信息，以及应用使用情况。不会收集游戏账号信息、登录信息及游戏数据。所收集的信息依照 Google 的政策处理。(https://policies.google.com/privacy, https://firebase.google.com/support/privacy)

##### 外部数据下载

应用更新检查、游戏内台词字幕、第三方模组等部分功能会从外部服务器下载所需数据。在此过程中，IP 地址等一般网络请求信息可能会被这些服务器获知，但不会发送用户信息。

##### 应用权限

- 网络、网络状态：连接游戏及下载数据
- 存储（Android 12 及以下）：保存截图及缓存
- 通知：截图保存时显示通知

##### 信息的删除

自动登录信息可在设置中删除。清除应用数据或卸载应用后，保存在设备上的信息将被删除，但已保存的截图会保留在设备上。

##### 政策变更

如有与个人信息相关的重要变更，将通过 GitHub 的 Release 或 README 告知。(https://github.com/antest1/GotoBrowser)
