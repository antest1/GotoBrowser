GotoBrowser 是一款可在 Android 设备上流畅游玩网页版（HTML5）舰队Collection 的应用程序。  
除启动游戏外，还提供多种便捷功能。


##### 主要功能
- 全屏游玩
- 资源缓存与优化，支持 PIP/多窗口
- 游戏语音字幕
- 静音模式/保存截图
- 绕过地区封锁
- 与 [Kcanotify](https://luckyjervis.com/kcanotify/) 联动及第三方 MOD
