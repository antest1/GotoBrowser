## PIP/多窗口

<img src="https://gotobrowser-docs.s3.ap-northeast-1.amazonaws.com/zh-cn/pip_multiwindow.webp"  width="550" style="max-width: 100%;" class="mb-3"/>

GotoBrowser 支持 PIP（画中画）模式及多窗口功能。（Android 8.0 及以上，三星 Galaxy 为 7.0 及以上）  
利用此功能，可以一边在设备上进行其他操作，一边游玩舰C。

##### PIP 模式
- PIP 模式下只能查看当前游戏画面，如需实际游玩，必须退出 PIP 模式。
  - 在 PIP 画面中点击 X 时，应用不会退出，而是转入后台。
- 在设置 → 游戏画面显示中开启“启用画中画模式”后，可通过以下方式进入 PIP 模式。
  - 按主页键或上滑返回主屏幕
  - 在游戏画面上双指捏合（缩小）
- “启用画中画模式”关闭时，返回主屏幕后应用将转入后台。
- 进入 PIP 模式时，已打开的设置画面会关闭，刷新/登出的确认对话框会被取消。

##### 多窗口模式
- 多窗口（分屏/弹出窗口）状态下可以正常游玩。
- 工具栏的显示和隐藏可按<span class="link" data-move="browserui">与平常相同的方式</span>操作。（轻触空白区域或滑动）
- 游戏画面紧贴分隔条显示时，请在设置 → 游戏画面显示中开启“[多视窗模式]在分隔条增添间隔”。
